# Harmony Shop — Green Edition

Готовый статический сайт для GitHub Pages. Превью товаров сделаны графически внутри сайта, поэтому он не использует непрофессиональные фотографии магазина.

Загрузите `index.html`, `styles.css`, `script.js` в корень репозитория и удалите старый `style.css`, если он остался.
