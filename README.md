# Harmony Shop

Статический сайт для GitHub Pages.

## Как установить
1. Распакуйте ZIP.
2. Загрузите `index.html`, `styles.css`, `script.js` и папку `assets` в корень GitHub-репозитория.
3. Включите GitHub Pages для ветки/папки, где лежит `index.html`.

Сайт не использует сервер и не требует базы данных.

## Что уже сделано
- Главная страница Harmony Shop.
- Адаптивный дизайн для телефона и компьютера.
- Меню ☰ слева.
- Главная / Каталог / О нас.
- Интерактивные категории: бахрома, ленты, резины, перья, декоративная тесьма.
- Для бахромы есть выбор длины: 5, 15, 20, 25 см и 1 метр.
- Телефон открывается как звонок.
- Адрес открывает Google Maps.
- Фотографии из предоставленных магазинных снимков использованы как превью.
